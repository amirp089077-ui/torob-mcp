# Torob MCP Server 🛒🔍

Model Context Protocol (MCP) server for **Torob (ترب)**, Iran's leading price comparison and smart e-commerce platform.

## Features
- 🔍 **Product Search**: Search millions of products across mobile, laptops, appliances, apparel, and supermarket goods with price range filters.
- 🏪 **Store Comparison**: Analyze all offering sellers, identifying the lowest price, highest rated seller, and price dispersion.
- 📉 **Price History & Trends**: Track price fluctuations over time and detect optimal buying opportunities.
- 🏷️ **Special Offers & Discounts**: Live daily deals and deep discounts.
- 🎯 **Deal Appraisal Score**: Algorithmic 0-100 deal rating considering competition, savings, and seller reliability.
- 🔐 **User Authentication**: Send/verify SMS OTP, session management, and bookmarks.
- 🌐 **Dual-Mode Connectivity**: Direct domestic connection with seamless Cloudflare Edge fallback.

## Live Cloudflare Worker
Endpoint: `https://torob-mcp.alphanet-edge.workers.dev`
